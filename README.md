# 妖股四象 (Yaogun Four Elements)

> **妖股不瞎涨，四象定乾坤**

基于500只A股妖股深度复盘总结的核心交易逻辑体系，所有能走出持续上涨行情的妖股，均完美契合四大核心逻辑，形成不可缺一的上涨闭环。

## 🎯 核心内容

| 模块 | 说明 |
|------|------|
| **四象详解** | 情绪锚点、题材内核、资金合力、筹码支撑（含真假对比表） |
| **3步识别法** | 情绪定性 → 内核筛选 → 结构确认（含操作清单） |
| **4大交易铁律** | 顺势而为、买在分歧、严控仓位、坚守止损 |
| **3大致命误区** | 伪妖真妖混淆、逆情绪追妖、无止损纪律 |
| **3句实战箴言** | 认知升维的核心心法 |
| **快速检查清单** | 盘中5分钟速用模板 |

## 🚀 快速开始

### 方法一：直接阅读

1. 阅读 `SKILL.md` 了解完整框架
2. 使用 `快速检查清单` 进行盘中筛选
3. 参考 `examples/` 中的实战案例

### 方法二：集成到Hermes Agent

```bash
# 克隆仓库
git clone https://github.com/你的用户名/yaogun-four-elements.git

# 安装到Hermes技能目录
cp -r yaogun-four-elements/SKILL.md ~/.hermes/skills/trading/yaogun-four-elements/

# 在Hermes中使用
skill_view(name='yaogun-four-elements')
```

## 📋 快速检查清单

```
【妖股四象快速检查清单】

□ 情绪锚点：两市成交>1.5万亿？上涨家数>下跌？
□ 题材内核：有政策/景气/需求支撑？非纯概念？
□ 资金合力：成交额>5亿？温和放量非暴量？
□ 筹码支撑：换手率5%-30%？筹码紧致？
□ 启动信号：涨停或涨幅>15%？突破压力位？

全部打勾 → 高确定性妖股候选
任一打叉 → 谨慎或排除
```

## ⚠️ 风险提示

> 妖股交易风险极高，本框架提高胜率但不保证盈利。
> 必须严格执行4大交易铁律，尤其是止损纪律。
> 市场风格切换时，框架需灵活调整，不可机械套用。
